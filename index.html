📲 التثبيت على الموبايل
    
آيفون (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".
أندرويد (Chrome): قائمة ⋮ ثم "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".

  
🔎 البحث في محركات البحث
    
عند الضغط على «بحث» تظهر أزرار Google وBing وDuckDuckGo والصور وYouTube. أدخل مواقعك المفضّلة (نطاقات مفصولة بفاصلة) لتقييد النتائج بها.

    
    

  
🧠 مزوّد التحليل الذكي للصورة
    
    

      
      
      
    

    

    
OCR: يقرأ النص المطبوع ويطابقه مع مكتبتك (يحتاج إنترنت أول مرة لتحميل المحرك). النموذج المفتوح: يعمل مع أي خادم متوافق مثل Ollama أو LM Studio أو OpenRouter. مع Ollama شغّله بالمتغير OLLAMA_ORIGINS=* واختر نموذجاً يدعم الصور.

  
🌐 تحديث المكتبة من الإنترنت
    
الصق رابط ملف تحديث (https). الصيغة: JSON فيه devices وlenses، أو نص أسطر: رقم البوردة | المعالج | الذاكرة | الاسم. مثال للاستضافة: GitHub (raw) أو Google Sheets منشور كـ TSV.

    
    

  
🔑 مفتاح Claude API (للنسخة المحفوظة)
    
يُحفظ داخل هذا الجهاز فقط ولا يُضاف للملف. كل تحليل يُحسب على حسابك. لا تشارك هاتفك مع أحد بعد حفظه.

    
    

  
📥 استيراد جماعي للمكتبة
    
كل سطر: رقم البوردة | المعالج | الذاكرة | الاسم (اختياري)
مثال: BOARD_X | Sunplus 1506T | SPI Flash 8MB

    
    

  
💾 نسخة احتياطية
    
البيانات محفوظة داخل متصفح هذا الجهاز فقط. انسخ النص أدناه واحفظه في مكان آمن (ملاحظات أو واتساب لنفسك)، ولصقه هنا لاستعادته.
